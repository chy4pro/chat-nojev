# 한국어 · 카카오톡 지원

English: [KOREAN.md](KOREAN.md)

## 왜 한국어를 못 읽었나

이 앱은 윈도우용 위챗을 기준으로 만들어졌고, 두 가지 가정이 중국어 전용이었습니다.

1. **OCR.** RapidOCR에 들어 있는 모델은 중국어·영어뿐입니다. 실제 카카오톡 창(760×1280, 화면에
   메시지 9개)에서 한국어를 `列是`, `吴`, `是` 같은 한자로 읽었고 한 프레임에 2.0초가 걸렸습니다.
   제대로 읽은 말풍선은 하나도 없었습니다.
2. **화자 구분.** `ocr.who_said`는 말풍선 배경이 초록색일 때(`G > R + 40 and G > B + 40`) 내 말로
   봅니다. 카카오톡의 내 말풍선은 `#FEE500`이라 9개 전부 상대방 말로 분류됐습니다. 내 말이 하나도
   없으면 지금이 누구 차례인지 판단할 수 없습니다.

같은 창에서 측정한 결과입니다.

| | RapidOCR (기존) | Windows.Media.Ocr (변경 후) |
|---|---|---|
| 정확히 읽은 말풍선 | 0 / 9 | 9 / 9 |
| 화자 구분 | 상대 9, 나 0 | 상대 5, 나 4 (정확) |
| 프레임당 시간 | 2.0초 | 0.20초 |

## 무엇을 바꿨나

- **`app/chatapps.py`** — 채팅 앱 하나에 `ChatApp` 한 줄. 프로세스 이름, 어떤 창이 대화창인지,
  어떤 OCR을 쓸지, 말풍선 안 조각을 무엇으로 이어 붙일지, "이 말풍선이 내 것인가"를 판정하는 색
  규칙이 들어갑니다. 위챗의 기존 동작은 `WECHAT` 줄에 그대로 남아 있습니다.
- **`app/ocr_windows.py`** — RapidOCR과 호출 모양이 같은 `Windows.Media.Ocr` 백엔드라 서로 갈아
  끼울 수 있습니다. RapidOCR처럼 오프라인입니다. 인식기는 운영체제 언어팩에 들어 있고 기기 밖으로
  나가는 데이터는 없습니다. 단어를 가로 간격이 벌어지는 곳에서 끊어 묶는데, 오른쪽에 붙는 내
  메시지와 그 옆 말풍선이 이 규칙으로 갈립니다. 인식 전에 2배로 확대하면 한 글자짜리 잡음 조각이
  사라집니다(+30ms, 3배로 키우면 다시 생깁니다).
- **`app/ocr.py`** — 앱에 따라 엔진을 고르고, 해당 언어 인식기가 없으면 조용히 RapidOCR로
  돌아갑니다. 패널 배경 위에 바로 찍힌 글자는 메시지가 아니라 이름표로 봅니다. 위챗은 보낸 사람
  이름을 회색으로 그리지만 카카오톡은 본문과 같은 진한 색이라, 회색만 보던 기존 규칙으로는 이름이
  매 턴 메시지로 섞여 들어왔습니다.
- **`app/capture.py`** — `find_chat_hwnd()`가 아는 앱을 모두 인식해 창과 프로필을 함께 돌려줍니다.
  카카오톡은 대화마다 창이 따로 뜨므로 친구 목록 창은 건너뛰고 남은 창 중 가장 큰 것을 고릅니다.

## 필요한 것

윈도우에 한국어 인식기가 설치돼 있어야 합니다. 한국어 언어팩에 포함돼 있습니다
(설정 → 시간 및 언어 → 언어 및 지역). 확인하는 명령입니다.

```powershell
[void][Windows.Media.Ocr.OcrEngine,Windows.Foundation,ContentType=WindowsRuntime]
[Windows.Media.Ocr.OcrEngine]::AvailableRecognizerLanguages | % { $_.LanguageTag }
```

없으면 RapidOCR로 돌아가고 한국어는 그대로 읽히지 않습니다.

## 다른 앱을 추가하려면

`app/chatapps.py`에 한 줄을 더합니다. 프로세스 이름, 고르거나 건너뛸 창 제목, OCR 백엔드, 조각을
이어 붙일 문자(중국어는 `""`, 한국어는 `" "`), 그리고 "이 배경색이 내 말풍선인가"를 답하는 함수가
필요합니다. 색은 실제 창에서 먼저 뽑아 보세요. 카카오톡 줄은 배경 `#BACEE0`, 상대 `#FFFFFF`,
내 말풍선 `#FEE500`으로 측정한 값입니다.

## 알려진 한계

- 작은 글자에서 오타가 납니다(`헷갈리던데` → `혯갈리던데`). 판단 모델은 넘겨 읽지만 디버그 화면에는
  그대로 보입니다.
- 1:1 대화만 측정했습니다. 단체방은 말풍선 위에 매번 이름이 붙는데, 이름 규칙이 잡을 것으로 보이나
  확인하지 않았습니다.
- 이모티콘·스티커 때문에 말풍선 앞에 한 글자가 붙어 들어오는 경우가 있습니다.
