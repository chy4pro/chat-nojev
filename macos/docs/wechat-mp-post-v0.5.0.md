## 正文

上篇说过我在微信边上挂了个小窗口：消息一进来，它告诉我三件事——对方什么意思（8 类意图）、有没有雷（风险 0–9 + 行动建议）、该怎么回（按话术给候选，点「填入」直接进输入框）。发不发，永远你自己按发送键。

这版 v0.5.0，把新用户最懵的三段全补上了。

**一，装完第一次打开，它自己会把话说清楚。**

以前：判断模型约 3.8 GB，不声不响就开始下载，很多人以为软件卡死了。现在首次启动会弹一个选择：**配 key 在线判断**（轻量、无下载），还是**下载离线模型**（约 3.8 GB，之后完全离线），或者先跳过。选过的不再问，之后在「模型设置」里随时能改。

**二，真要下载，进度看得见。**

状态行实时显示「下载判断模型 34% · 1.2/3.8 GB」，下完进加载、预热，全程有字；失败红字说明原因。再也不会一片空白干等着。

【配图 2b：`docs/download-progress.png`（下载进度实拍，红框标注状态行「下载判断模型 7% · 0.3/3.8 GB」；正式发布可用无框版）】

**三，面板默认三组话术——第三组是阴阳怪气。**

高情商话术、贴吧老哥 v1.0 之外，现在默认再给你一组「阴阳怪气」：表面客气、话里带刺，「哦」「呢」「辛苦你了」配反问，让对方不好发作又挑不出理。实测大家都会手动把第三格勾成它，那不如默认就有。

【配图 2：`docs/release-v0.5.0.png`（0.5.0 面板实拍：左微信原话「客户很急，快点」→ 右侧催进度 99%、留神 5/9、三组候选，输入框里是刚「填入」的那条）】

**自带 key 也一直是支持的**，模型设置里三组密钥各管各的：判断 · Jev（TypeSafe 或 OpenRouter 这类兼容网关）、生成 · OpenAI 兼容（DeepSeek、智谱、本地 Ollama 都行）、生成 · Anthropic 兼容。「获取模型列表」拉下来选，「测试连接」发条固定问候实测，保存后重启生效。不配也能用：判断跑本地模型，生成层有内置共享 key。

【配图 3：`docs/settings-jev.png` / `settings-openai.png` / `settings-anthropic.png`（模型设置三个页签，**OpenAI 那张的服务地址记得打码**）】

**装**：macOS 13+（Apple Silicon），GitHub 找 `jev-chat/jev-chat-jarvis-mac`，Releases 下载 zip，拖进「应用程序」，第一次右键 → 打开（没做公证，只需这一次）。老用户直接覆盖安装，配置不受影响——旧版「启动一片空白」这版根治，建议更新。MIT 开源。
