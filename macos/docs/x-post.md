**发之前三件事**：

1. 第一条**附上 GIF**（X 单文件上限 15MB，1.2MB 没问题）。

### 3/7（219/280）

```
关键设计是把判断和生成分开。

判断层用「无嘴」小模型：一次前向同时出意图和风险两个分布，全程不写一个字——不写字的模型不会编。跑在本地，不出网、不要 key，约 0.7 秒。

生成层才要文采，交给任意 OpenAI / Anthropic 兼容端点。
```

### 4/7（197/280）

```
生成的候选不直接给你，先丢回本地模型排序——API 经常混进踩雷选项。

实测一句批评「这做的什么玩意」，生成的「哈哈，老板，我这就改！」被本地模型压到第 3（6.6%），「对不起，我马上改！」排第 1（57.7%）。

### 5/7（268/280）

```
边界说清楚：不注入、不 hook、不解密微信数据库、不自动发送任何消息。对微信来说就是「屏幕上有个人在看」，没有封号风险。

唯一一次写入是点「填入」，写完会读回来确认，没写进去就如实报失败。消息内容会发给写候选的那个端点；判断层全程本地不出网（生成层也能换成本地 Ollama）。

## 发布细节

- **首帧就是封面**：X 拿 GIF 第一帧当时间线缩略图。现在是「已填入候选 #1」那一刻 —— 左边微信、右边面板（夸奖 / 安全 2/9 / 三条候选），一眼能看懂，不用另做封面。
- **标签别多**：1–2 个足够（`#开源` `#macOS`）。堆标签在中文推特上像营销号，反而压触达。
- **时间**：北京时间工作日 **12:00–13:00** 或 **21:00–23:00**，中文开发者最活跃。
- **转发靠哪句**：「判断层完全本地、不出网」和「零封号风险」这两点是这条贴最可能被转的理由，前三条里已经各占了一个位置，别挪到后面。
- **先发 thread**：想试水可以先发单条版，数据还行再补 thread（X 上「追一条」比改主贴有效）。
- **有人杠「这不就是偷看聊天记录」**：直接回第 5 条那一段 —— 只读你自己屏幕上、你自己账号的内容，不注入不发送；判断层全程本地不出网。这是最容易被误解的一点，回得具体比回得客气有用。
